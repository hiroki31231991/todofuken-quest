# 都道府県クエスト ～47の宝をさがす旅～ をご購入ありがとうございます

47都道府県をクイズで学ぶ、レトロRPG風の学習ゲームです。
**インストール不要・インターネット接続不要**で動きます（ゲームの進行は使った端末のブラウザ内に自動保存されます）。

同梱物はこの1ファイルだけです：

- `都道府県クエスト.html` … ゲーム本体（これ単体で完結しています）

---

## ① パソコンですぐ遊ぶ（いちばん簡単）

`都道府県クエスト.html` を**ダブルクリック**するだけ。
お使いのブラウザ（Chrome / Edge / Safari など）でゲームが開きます。

> うまく開かないときは、ファイルを右クリック →「プログラムから開く」→ ブラウザを選んでください。

---

## ② タブレット・スマホで遊ぶ／クラス全員に配る

タブレットやスマホはローカルのHTMLファイルを開きにくいので、その場合は
**Google Apps Script（GAS）に置いて「URL」で配る方法**がおすすめです。
Googleアカウントがあれば無料で、5分ほどでできます。

1. <https://script.google.com/> を開き、「＋ 新しいプロジェクト」
2. 最初からある `コード.gs` の中身を消して、次を貼り付け：

   ```javascript
   function doGet() {
     return HtmlService.createHtmlOutputFromFile('Index')
       .setTitle('都道府県クエスト ～47の宝をさがす旅～')
       .addMetaTag('viewport', 'width=device-width, initial-scale=1.0, user-scalable=no')
       .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL);
   }
   ```

3. ファイル一覧の「＋」→「HTML」を選び、ファイル名を必ず **`Index`**（拡張子なし）にする
   → そこに `都道府県クエスト.html` の中身を**全部コピペ**
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**Googleアカウントを持つ全員**（校内限定にしたい場合は「同じドメインのユーザー」）
5. 「デプロイ」→ 初回は承認を許可 → 発行された `…/exec` のURLを子どもたちに配る

> このURLは**あなた自身のGoogleアカウント**で発行されます。あなたのものなので、安心して教室で使えます。

- 十字キー（画面のボタン）で移動、宝箱や人に近づいて調べるとクイズが出ます。

- 音はメニューからON/OFFできます。
